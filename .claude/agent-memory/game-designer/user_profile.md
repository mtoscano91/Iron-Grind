Manuel Toscano (mtoscano@itba.edu.ar) is the sole designer and developer on Project Iron Grind, a mobile MMORPG (Unity 6.3 LTS, iOS primary). He has a structured, rigorous authoring style — he reads and locks upstream GDDs before writing downstream ones, and maintains strict traceability between documents.

He treats design consultations as expert advisory sessions, not passive instruction. He comes in with locked decisions already stated and asks targeted analytical questions about gaps, edge cases, and what he might have missed — not "what should I do."

He is comfortable with formal game design theory language (MDA, SDT, flow state, tuning knobs) and does not need these explained from scratch.

**How to apply:** Skip foundational explanations. Lead with the finding, then the reasoning. Match his precision — he wants specific rule language, not design platitudes. When he asks for a concise analysis, respect the word budget.
