Project Iron Grind is a mobile MMORPG targeting iOS primary (Android later), landscape orientation, touch-only input.

**Why:** All UX decisions must be scoped to thumb-reachable two-thumb landscape hold. No hover interactions. Safe area insets required for notched iPhones (iPhone X+).

**Session length:** 20–60 minutes typical; grind sessions can extend 2+ hours. Fatigue and long-session ergonomics are a live concern in every input design decision.

**Target audience:** Ages 22–38, Korean mobile MMO veterans (Lineage M, MU Origin, Ragnarok Origin conventions are already internalized). Comparable titles: Knight Online (2004), Curse of Aros, Risk Your Life.

**Game pillars (UX-relevant):**
- Pillar 1: Earned Power — no handholding, no shortcuts
- Pillar 2: Rhythm Mastery — precise positional control required; input must be exact, not floaty
- Pillar 3: Social Gravity — shared zones, party play; social UI visibility matters

**How to apply:** Frame every input and feedback recommendation against these pillars. Precision over feel-good deceleration (Pillar 2). Long-session ergonomics over flashy input patterns (2+ hour sessions). Audience familiarity with Korean MMO conventions means discoverability concerns are lower than average — convention-matching is higher priority.
